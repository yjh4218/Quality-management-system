## 2. 잠재 위험 (Potential Risks)

1. **자동 배포 파이프라인 위험**: `main` 푸시 시 Hugging Face로 즉시 배포되므로 단계별 충분한 검증 없는 커밋/푸시가 프로덕션 중단 유발 가능.
2. **프론트엔드 모놀리식 컴포넌트**: `ProductDrawer.jsx`가 8,500줄을 초과하여 신규 규제/서류 필드 추가 시 회귀 결함 위험 높음.
3. **CORS 와일드카드 허용**: `*.kro.kr`, `*.pages.dev`, `*.hf.space` 등 광범위 도메인 허용 패턴 사용.
4. **프론트엔드 자동화 테스트 부재**: 화면 렌더링, 폼 유효성 검사, 결재 버튼 활성화 등에 대한 자동 회귀 검증 도구 없음.

## 3. 기능 영역별 갭 분석 (Cosmetics vs Medical Devices)

| 영역 | 현행 시스템 (Current) | 화장품 책임판매업 요구사항 | 의료기기 (ISO 13485) 요구사항 | 갭(추가/보강 필요) |
| :--- | :--- | :--- | :--- | :--- |
| **제품 마스터** | 단품/세트, 화장품 포장재, 규제 성분 스캔 | 책임판매업 정보, 기능성 여부, 국문/영문 표시기준 | 기기 등급, 사용목적, UDI, 수명주기, 소프트웨어 버전 | 제품군 분리, 의료기기 마스터 신설, 규제식별자 분리 |
| **문서 관리 (DMS)** | 단순 파일 업로드 및 링크 | 품질/안전관리 매뉴얼, SOP, 제품표준서, 성적서 | ISO 13485 품질매뉴얼, DHF, DMR, 기술문서 | 통제문서 라이프사이클 (DRAFT~EFFECTIVE), revision 통제 |
| **설계 개발** | 미구현 | 해당 없음 (OEM/ODM 위탁 기준) | 설계입력/출력/검증/유효성확인/이관, DHF | 신규 설계개발 추적 매트릭스 모듈 구축 |
| **위험 관리** | 미구현 | 원료 안전성 검토 (안전성 보고서) | ISO 14971 위해요인, 위험통제, 잔여위험 | 위험관리 및 추적 매트릭스 신설 |
| **불만 / 이상사례** | 단순 0~5단계 클레임, 제조사 공유 | 이상사례 수집, 평가, 식약처 보고판단, 안전조치 | 시판 후 불만, Vigilance, MDR/MDV 규제보고 | LOT 미상 접수 허용, 이상사례/불만 분기, 보고기한 산정 |
| **CAPA** | 클레임 내 텍스트 필드 | 시정 및 예방조치 (운영 권고) | 필수 CAPA 프로세스, 원인규명, 효과성 검증 | 독립 CAPA 모듈, 사건/불만/심사 연계 |
| **공급업체 관리** | 제조사 등록, Audit 실사 점검 | 위탁제조업체 관리, 시험성적서 검토 | 중요 공급업체 평가, 품질협약, 구매품 검증 | 공급업체 승인상태와 실사점수 분리, 자격 관리 |
| **전자서명 / 원본** | 로그인 기반 승인 버튼 | 종이 원본 또는 전자 관리 | 21 CFR Part 11 적합 전자서명, 서명 의미 | 전자서명 정책 수립 및 재인증 체계 검토 |
